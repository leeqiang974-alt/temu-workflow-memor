# 2026-07-07 Adaptive Multi-Scene Reasoning Rule

This update generalizes the L096 lesson without turning it into a mechanical template.

## Core rule

For every `L0xx` scene bank or T-first image redo, first define the product's realistic use envelope:

- actual function
- support/contact surface
- indoor/outdoor boundary
- installation or placement method
- likely buyer scenarios
- safe props and background atmosphere
- forbidden contexts

Then decide whether broad multi-scene rotation is justified.

## Important distinction

Broad multi-scene thinking is encouraged when the product naturally supports multiple real use cases. Example: L096 folding portable barbecue grill can rotate wild camping, lawn picnic, Western family/friends backyard gathering, courtyard/patio outdoor meal prep, RV campsite, garden party, park picnic, terrace/deck floor, and open-air family outdoor dining.

Broad multi-scene thinking is not automatic for every product. Products with narrow functional contexts should stay inside that context and differentiate through:

- room or location subtype
- color palette
- camera distance and depth
- product scale and placement
- safe props
- source PNG variation
- composition and left/right position

Example: under-sink racks, drawer organizers, cabinet-interior products, and strict structural organizers must not be moved to unrelated rooms or surfaces just to create variety.

## Review gate

Claude/NVIDIA pre-generation review must check more than prompt count. It must answer:

1. Is this a real place where a buyer would use this exact product?
2. Is the support/contact surface physically correct?
3. Is broad multi-scene rotation justified for this product?
4. If the product has a narrow use envelope, are differentiation dimensions still strong enough without leaving that envelope?
5. Are forbidden contexts and high-risk product locks reflected in the source PNG/scene allocation plan?

If the scene is beautiful but the use context is wrong, the image fails.
